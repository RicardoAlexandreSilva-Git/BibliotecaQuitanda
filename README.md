# BibliotecaQuitanda

## Sobre o Projeto

Projeto desenvolvido em Java utilizando o IntelliJ IDEA com o objetivo de aperfeiçoar conhecimentos em Programação Orientada a Objetos (POO), estrutura em camadas (DAO e Service), Collections, Stream API, Expressões Lambda e tratamento de exceções.

O sistema simula o funcionamento básico de uma biblioteca, permitindo o gerenciamento de clientes e livros através de operações CRUD (Create, Read, Update e Delete), além do controle de empréstimos e devoluções.

## Funcionalidades

* Cadastro de clientes
* Cadastro de livros
* Listagem de clientes
* Listagem de livros
* Remoção de clientes
* Remoção de livros
* Empréstimo de livros
* Devolução de livros
* Controle de estoque dos livros
* Tratamento de exceções personalizadas
* Utilização de Stream API e Expressões Lambda

## Tecnologias Utilizadas

* Java
* IntelliJ IDEA
* Programação Orientada a Objetos (POO)
* Collections Framework
* Stream API
* Expressões Lambda
* Exceptions Personalizadas
* DAO Pattern
* Service Layer
