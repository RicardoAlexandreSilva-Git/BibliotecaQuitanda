# BibliotecaQuitanda
Aperfeiçoando habilidades.

Projeto criado no IntellijIDEA para aperfeiçoar conhecimento JAVA.
Projeto simula uma biblioteca com CRUD de clientes e livros.
Melhoria futura inclusão de restrição para devolução de livros onde cada livro devolvido ser informado o cliente que o
pegou emprestado para devolução. Projeto atual em versão 1, demais implementações seram realizadas após modulo POSTGreeSQL.
